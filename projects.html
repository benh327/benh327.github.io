Project Description

These parameters include three key metrics: Stimp rating (green speed), trueness, and smoothness. The software was developed in Python and utilized some of the same frameworks used by the Sphero Edu app, including the bleak library used for BLE (Bluetooth Low Energy) communication. Through the BLE connection, we were able to handle all of the sensor data and timestamps so that we could model and predict the turf metrics. Data was collected primarily at the Auburn University Turfgrass Unit where a variety of testing surfaces are used for university research.

Automatic Video Highlight Detection and Captioning

Project Description

For my Applied Statistics and Machine Learning Course we were tasked with making a term project that integrates concepts from class. My grouped opted for a model that would take a video as an input (i.e. a sporting event), detect the point in time of particular highlights, and then generate a text based on the events of the highlight. The model combined multiple different existing models and datasets to allow it to exhibit the full functionality required of the project.

The two primary elements of the model are the highlight dection model which uses a boundary-matching network and the video captioning which is done by an Large-Language Model (LLM) and Computer Vision model such as Large Language and Vision Assistant (LLaVA). The Boundary-Matching Network generates a confidence map throughout the duration of the video to determine possible start and end points of a highlight. LLaVA is used to first identify actions within the video using using a vision encoder matrix integrated in the model. The model then have a projection matrix capable of translating the identified action into an LLM tokens for caption generation.

ELEC-3320 FMCW Radar Project

Project Description

To meet ABET accreditation requirements students were required to design a project from one of the topics in the class (ELEC-3320) such as waveguides, radar, wireless comms, or electromagetic compatilibility. Due to my interest in the topic and its intersection with signal processing, I opted for a radar simulation project.

This project is designed to model the type of radar system that has become very common in short-range telemetry applications such as in automotive. The method of transmitting and receiving does behave rather differently from a tradition pulse radar system. By contrast, this relies on a continuous wave transmission with the carrier frequency modulated by a chirp (usually a sawtooth or triangle wave), hence the name Frequency-Modulated Continuous-Wave RADAR or FMCW RADAR. These systems have the advantage of being able to operate at very high frequency and low power allowing for a fast, simple, short-range detection system commonly used in implementing modern automotive features like adaptive cruise control and emergency collision detection. These systems rely on being both accurate and speed to be able to identify objects in the front of the vehicle with a high degree of accuracy and at a very high speed.
